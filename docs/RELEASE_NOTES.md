# Create Sky v0.1.8

Minecraft **1.21.1**, NeoForge **21.1.264** and Java **21** remain pinned.

## Settlements and progression

- Add Sky Villages 1.0.6 with bounded sky placement, repaired template pools and
  village discovery for Delivery Quests. Repair generated jukebox placement.
- Fix the masked foundation diamond rule and reduce mineral yields to nominal
  aggregate rates of 0.025% diamond ore and 0.15% emerald ore. Crops and chest
  loot retain their existing variety.
- Preserve stone/deepslate ore distinctions during recipe unification. Remove
  overlapping platinum crushing recipes and repair Propulsion processing times.
- Own the six stock delivery templates with direct wording and unchanged cargo
  and rewards. Journal descriptions clarify supplied cargo, fuel production,
  quartz access and crafting arrangements; objectives and progress IDs stay stable.
- Default new Prism installs to Java 21 Generational ZGC with an 8 GiB maximum heap.
  The server retains its existing collector defaults.

## Atlas

World & ores includes a repeatable village survey with per-village foundation
and chest counts, natural-placement coverage, provenance and stale-data warnings.
The internal web app is not included in playable distributions.

## Installation

Use `Create-Sky-0.1.8.mrpack`, `Create-Sky-0.1.8-prism-references.zip` or
`Create-Sky-0.1.8-server-references.zip`. Prism/server reference installations
require empack 0.8.2-beta; Unix servers also require Python 3 for the maintained
foreground-launch helper. Keep the complete server archive together.

Stop instances before updating. Preserve local settings, access lists and saves.
Existing chunks are not regenerated by the update; new settlement generation
requires new chunks. A world reset is optional and must be an operator decision.
Clear the corresponding client DH cache when deliberately replacing a server world.

## Verification

Twenty-four controlled villages across four seeds contained 0–5 diamond ore
(median 2) and 5–33 emerald ore (median 17). Natural checks found 74 valid starts
in 100 candidate cells; eight fully generated villages completed without shielded
placement failures. These measurements do not prove safe landings, completed
cargo deliveries or multiplayer Lootr balance.

Native recipe/journal checks, configuration audits, Atlas tests and reference
build checks passed. See the [player guides](https://github.com/mannie-exe/create_sky/blob/v0.1.8/docs/README.md)
and [structure measurements](https://github.com/mannie-exe/create_sky/blob/v0.1.8/docs/development/structures.md).
